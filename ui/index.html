OmniBox Worker

网盘 · 爬虫 · 媒体库 · 订阅

概览

当前部署的运行状态。所有数据来自服务端，网盘凭据不会出现在浏览器。

快速开始

  1. 在「网盘挂载」添加 OpenList 存储（需先在 OpenList 后台建管理员）
  2. 在「网盘源」把挂载目录登记为源；或在「爬虫源」导入 OmniBox JS 脚本
  3. 在「媒体库」扫描目录并刮削海报（需 TMDB API Key）
  4. 在「订阅链接」勾选需要的源，生成地址导入 TVBox

媒体库

扫描网盘目录生成媒体条目，刮削后显示海报。海报墙与 TVBox 目录浏览互不干扰。

爬虫源

导入 OmniBox JS 爬虫脚本。注意：EdgeOne 无 Chromium，依赖嗅探的脚本播放能力受限。
